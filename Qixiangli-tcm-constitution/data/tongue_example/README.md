# 舌象数据格式

```
data/tongue/
├── labels.csv
└── images/0001.jpg ...
```

`labels.csv`（UTF-8）：

```csv
path,舌色,苔色,苔质,齿痕,裂纹,patient,split
images/0001.jpg,淡红,白,薄,无,无,p001,train
images/0002.jpg,淡白,白,厚,有,无,p002,val
```

| 列 | 取值 |
|---|---|
| 舌色 | 淡白 / 淡红 / 红 / 红绛 / 紫暗 |
| 苔色 | 白 / 黄 / 少苔 |
| 苔质 | 薄 / 厚 / 腻 |
| 齿痕、裂纹 | 无 / 有 |

- 标签留空 = 该图未标注此项（训练时忽略）。
- `split` 可省略；若有 `patient` 列将按患者划分验证集。
- 采集建议：自然光、统一白平衡/色卡、伸舌放松、避免染苔食物（咖啡、饮料、药物）。
- 标签由执业中医师标注，建议双人标注并计算 Cohen's κ。
- 真实图像属于个人健康数据：须知情同意，**不要提交到 GitHub**（`.gitignore` 已排除 `data/real/`，建议放 `data/real/`）。
